# Emoji Mega Pack

Emoji Mega Pack (3,900 iOS Apple Emojis), organized and published by Adam Misosky.
Source: https://www.figma.com/community/file/1079620626888497486/emoji-mega-pack-3-900-ios-apple-emojis
Community file states CC BY 4.0: https://creativecommons.org/licenses/by/4.0/
Exported PNG components at their original 72 x 72 size. Original emoji artwork is identified by the source as Apple artwork; this is not an official Apple package.
Selected components: Red Heart, Fire, Smiling Face With Heart Eyes, Smiling Face With Hearts, Hundred Points, Musical Notes, Thought Balloon, Flag Brazil, Rainbow, Gem Stone.
Files renamed for integration. Sphere adds CSS motion; source PNG artwork is unchanged.

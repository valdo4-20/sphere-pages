# Sphere — assets de conquistas

149 símbolos SVG, 149 moedas SVG e materiais auxiliares. Abra index.html para explorar o catálogo sem servidor.

- music/: música, biblioteca, sequências e curadoria.
- fitness/: caminhada, corrida, tempo, distância e passos estimados.
- friends/: amizades, compartilhamentos, desafios e Cristal de Aura.
- coins/: moedas completas em SVG, com os materiais aplicados.
- themes/maos-dadas.svg: símbolo dedicado de conexão.
- materials/: Diamante e Cristal de Aura facetados.
- manifest.json: associação de ID, título, material e arquivo.

Hierarquia individual: Bronze, Prata, Ouro, Platina, Topázio, Esmeralda, Safira, Rubi, Diamante. O Cristal de Aura é reservado aos marcos sociais supremos. Ametista permanece compatível com dados anteriores no aplicativo.

Os símbolos são composições vetoriais do projeto com motivos Lucide. Consulte LICENSE-LUCIDE.txt para o licenciamento dos motivos de origem. Cada marco utiliza um motivo vetorial distinto, sem números ou ornamentos dentro do símbolo. Não incluem fontes, arquivos de música ou dados pessoais.

Regeneração: node scripts/build-achievement-assets.mjs e node scripts/package-achievement-catalog.mjs no projeto principal.
